# vue

## Usage

This project uses JSON-Server for a mock backend. Run npm run server on a terminal and npm run dev on another.

### Install Dependencies

```bash
npm install
```

### Run JSON Server

The server will run on http://localhost:8000 To change this, go to package.json and change the "server" script.

```bash
npm run server
```

### Run Vite Frontend

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
